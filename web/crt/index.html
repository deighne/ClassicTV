1. Pincushion

Pincushion distortion causes the left and right edges of the picture to bow inward (barrel) or outward (pincushion). Use the test pattern to verify that vertical lines run straight from top to bottom across the full screen width.

Vertical lines should be perfectly straight and evenly spaced. Bowing indicates pincushion error.

Access

  • Power on the set.
  • Press and hold MENU on the front panel for ~5 seconds to enter the service menu.
  • Navigate to H PINCUSHION (horizontal edge bow) or V PINCUSHION (top/bottom bow).
  • Exit service menu; changes are saved automatically.

Adjustment Directions

Increase (CW / +)
Pushes left/right edges outward — corrects inward bow
Decrease (CCW / −)
Pulls left/right edges inward — corrects outward bow

Notes

  • Allow the set to warm up for at least 20 minutes before calibrating.
  • Horizontal and vertical pincushion interact slightly; adjust H first, then V.
  • Check corner geometry after each adjustment; pincushion correction can introduce corner distortion.

2. Trapezoid (Keystone)

Trapezoidal (keystone) distortion causes the image to be wider at one end than the other — the raster looks like a trapezoid instead of a rectangle. Use the test pattern to verify that the top and bottom edges are the same width and that corners are square.

Top and bottom edges should be equal width. The outer white border should form a perfect rectangle. Slanted sides indicate trapezoid error.

Trapezoid (Keystone) Control — Physical Location & Effect
SERVICE MENU > H KEYSTONE / TRAPEZOID
  CORRECT (rectangle)        TOP-WIDE (adjust CCW)     BOTTOM-WIDE (adjust CW)

  +--------------------+      +----------------------+   +-----------------+
  |                    |     /                        \  |                  |
  |                    |    /                          \ |                  |
  |                    |   |                            ||                  |
  +--------------------+    \                          /  \                /
                              +----------------------+     +--------------+

  Top == Bottom width        Top edge WIDER than bottom   Bottom edge WIDER than top
  (correct)                  (decrease KEYSTONE value)    (increase KEYSTONE value)

Access

  • Enter service menu (hold MENU ~5 seconds).
  • Navigate to H KEYSTONE or TRAPEZOID depending on firmware version.
  • Some KV-34HS510 units also expose V KEYSTONE for top-to-bottom taper.

Adjustment Directions

Increase (CW / +)
Widens the bottom of the image relative to the top
Decrease (CCW / −)
Widens the top of the image relative to the bottom

Notes

  • Use the outer white border of the grid pattern to judge top/bottom width equality.
  • A slight tilt of the deflection yoke can cause trapezoid error that software cannot fully correct; check yoke alignment if error is severe.
  • Trapezoid and pincushion interact — adjust one, then re-check the other.

3. Convergence

Convergence error means the red, green, and blue electron beams do not land on exactly the same phosphor dot. This produces color fringing on sharp edges (e.g., white text on black shows a colored shadow). Use the dot pattern with the red/green crosshairs to assess center and corner convergence.

White dots should appear pure white with no colored fringe. Red (vertical) and green (horizontal) crosshairs should overlap to form a single yellow cross at dead center. Color fringing on dots indicates convergence error.

Access

  • Static (center) convergence: Adjust the 4-pole magnet rings on the deflection yoke neck. Rotate to shift the red and blue beams relative to green. Small increments — these are sensitive.
  • Dynamic (corner) convergence: Adjust the 6-pole magnet rings and the corner purity tabs. Correct one corner at a time while monitoring the others.
  • No service menu access is needed for convergence; all adjustments are physical magnets.
  • After adjusting, run the TV for 30 minutes and re-check — magnetic adjustments drift with temperature.

Adjustment Directions

4-pole ring rotation (CW)
Shifts red/blue beams diagonally; affects center convergence symmetrically
4-pole ring rotation (CCW)
Shifts in opposite diagonal direction; use in combination with a second ring to isolate horizontal or vertical shift
6-pole ring rotation
Corrects bow/curve of convergence in corners without affecting center
Purity tabs (flex outward/inward)
Adjusts corner color purity independently on each corner

Notes

  • Degauss the set first (unplug and replug) — stray magnetic fields cause convergence errors that magnet adjustment cannot fix.
  • Work with the set warmed up (20+ minutes); cold convergence differs from operating convergence.
  • Convergence adjustments affect the magnetic field inside the CRT and can cause purity errors in other areas. Re-check the full screen after each change.
  • A shadow mask CRT (such as the KV-34HS510) can only correct convergence to within ~0.5–1mm; some fringing at screen edges is normal.
